# Банк гипотез

Сюда записывается любая идея, которую стоит проверить: из встреч, от Тагира, из статей, из наблюдений
на графиках, из результатов прошлых проверок. Раз в неделю (понедельник, вместе с еженедельным
отчётом) из банка выбирается, что берём в работу. Результат проверки — строка в
[журнале изменений](results/model_changelog.md), здесь меняется только статус и ссылка.

## Как приоритизировать (предложение — обсудить Тимуру и Денису)

Каждой гипотезе три оценки от 1 до 5:

| оценка | что значит | 1 | 5 |
|---|---|---|---|
| **В** — влияние | насколько изменится главный результат (итог стратегии или преимущество модели), если гипотеза верна | косметика | меняет вывод «работает / не работает» |
| **У** — уверенность | сколько уже есть оснований, что она верна (наши результаты, наблюдения, литература) | чистая догадка | есть прямые признаки в данных |
| **С** — стоимость | сколько стоит проверить (5 — дёшево): данные есть, код есть, считается за часы | нужны новые данные и недели работы | готово за вечер |

**Приоритет = В × У × С** (до 125). Правила выбора на неделю:

1. Сначала **проверки достоверности** (тип «Д»): всё, что может отменить уже полученный результат —
   издержки, дивиденды, исполнение. Они идут вне очереди, пока главный результат не проверен.
2. Затем 2–3 гипотезы с наибольшим приоритетом.
3. Плюс одна «дикая карта» — гипотеза с высоким влиянием, даже если уверенность низкая: иначе банк
   превращается в доводку параметров.
4. До проверки записываем **критерий вердикта**: на каком периоде выбираем, на каком проверяем,
   какие метрики (профит-фактор, итог без 2 лучших сделок, t сделки, годы в плюсе), что считаем
   «помогло». Сравнение только по сумме процентов не годится: победа может держаться на 2–3 сделках.
5. Каждый вердикт — с графиком, на котором видно, почему он такой (не только таблица).

Статусы: 🆕 новая · 🔬 в работе · ✅ подтвердилась · ❌ не подтвердилась · ⏸ отложена (нет данных /
ждёт другой) · ❓ надо уточнить формулировку.
