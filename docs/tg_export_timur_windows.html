Выгрузка Telegram-канала

Для Windows. В архиве tg_export_windows.zip три файла — распакуйте их в любую папку.

Сегодня, на своём ноутбуке

  1. Зайдите на my.telegram.org своим номером → API development tools → заполните два поля (любое название) → Create. Перепишите api_id и api_hash.
  2. Дважды щёлкните PROBA.bat. Python и всё нужное он поставит сам. Если Windows предупредит — «Подробнее» → «Выполнить в любом случае».
  3. Введите api_id, api_hash, свой телефон и код из Telegram. Выберите любой открытый канал.
  4. Откроется папка с файлом …_text.zip — пришлите его в исследовательский чат.

У друга

  1. Дважды щёлкните START.bat.
  2. Телефон — друга, код придёт ему в Telegram. Пароль друг вводит сам (при вводе его не видно — так и должно быть).
  3. Наберите часть названия канала и выберите номер. Ждите — несколько минут.
  4. Откроется папка с архивами .zip — пришлите их в чат (больше 50 МБ — на Яндекс Диск).

Не получилось? Сфотографируйте окно и пришлите в чат. Оборвалось — просто запустите START.bat ещё раз.

Безопасность. Код и пароль друга вводить только в окно скрипта. В конце скрипт сам выходит из аккаунта друга.

Платный канал — только для нашей проверки, никуда не публикуем.
