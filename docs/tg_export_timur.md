Выгрузка Telegram-канала (H78) — инструкция для Тимура

Скрипт tg_export.py (файл ниже) скачивает всю историю канала: текст, даты, правки, просмотры, картинки. Нужен аккаунт, который подписан на канал. Сессия хранится только в памяти, в конце скрипт сам выходит из аккаунта — на ноутбуке доступа не остаётся.

ДО ВЕЧЕРА (на своём ноутбуке, ~15 мин)
1. Ключи: my.telegram.org → войти своим номером → API development tools → создать приложение (название любое, например tg_export) → записать api_id и api_hash. Ключи принадлежат приложению, другу с ними тоже можно войти.
2. Python 3.9+: python.org (Windows — галочка «Add Python to PATH»). Потом в терминале:
   Windows:  py -m pip install telethon
   macOS:    python3 -m pip install telethon
3. Проба на своём аккаунте и любом открытом канале (заодно проверка вживую):
   py tg_export.py --limit 50        (macOS: python3 tg_export.py --limit 50)
   Скрипт спросит api_id, api_hash, телефон, код (придёт в приложение Telegram), облачный пароль, если есть. Потом — часть названия канала и номер из списка. Должны появиться папка tg_<канал>_<дата> и архивы _text.zip / _media.zip. Пришли _text.zip в этот чат — проверю.

У ДРУГА
4. Запусти скрипт так же, без --limit. Телефон — друга, код придёт ему в Telegram, облачный пароль друг вводит сам (на экране не видно). Выбрать платный канал.
5. Ждать: примерно 1–3 минуты на 1000 сообщений с картинками. Можно только текст (быстрее): добавь --no-media.
6. Если оборвалось — запусти ещё раз с той же папкой: --out tg_<канал>_<дата>. Продолжит с места обрыва (войти придётся заново).
7. В конце скрипт спросит «Выгрузить ещё канал?» и выйдет из аккаунта. Друг может убедиться: Telegram → Настройки → Устройства — сеанса tg_export нет.

ПОСЛЕ
8. _text.zip — в этот чат. _media.zip — сюда, если меньше 50 МБ, иначе на Яндекс Диск (Папка для переноса данных).

ЕСЛИ СКРИПТ НЕ ЗАПУСТИЛСЯ
Telegram Desktop → открыть канал → ⋮ → «Экспорт истории чата» → формат JSON. Не сработает, если автор запретил копирование, — тогда только скрипт.

ВАЖНО
• Код из Telegram и облачный пароль друга никому не пересылать, вводить только в скрипт.
• Другу придёт уведомление о новом входе — это нормально.
• Содержимое платного канала — только для нашей проверки, никуда не публикуем.
