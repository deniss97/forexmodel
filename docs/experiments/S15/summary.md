# S15. Только при высокой волатильности

**Семейство:** стратегия без ML (импульс) · **база:** B01 · **гипотеза:** — · **вердикт:** не подтверждено (выбор лучше, проверка как база)

**Что проверяли.** Входить, только если ATR сигнального часа не ниже медианы ATR обучающего периода. Выход как в базе, все 8 рынков.

**Зачем.** Преимущество должно быть больше в активном рынке; сделок вдвое меньше — меньше и свопов.

**Итог простыми словами.** Не подтвердилось: на выборе 2016–2020 заметно лучше базы, на проверке — как база, на металлах чуть хуже. Кандидат, но включать рано.

**Издержки:** профиль `base` (спред и свопы брокера)
