# M14. Сброс тренда по EMA5 4-часовых свечей

**Семейство:** модель CatBoost · **база:** M13 · **гипотеза:** — · **вердикт:** не помогло

**Что проверяли.** Гейт входа — гейт C со сбросом по EMA5 4-часовых свечей — тренд не считается «вверх», пока 4-часовая свеча закрывается ниже EMA5 (и наоборот). Идея из ноутбука S_TrendFiter.

**Зачем.** Убрать входы в «слабой зоне» тренда, которые видны на графике.

**Итог простыми словами.** Сделок меньше, результат сделки тот же, итог ниже.

**Издержки:** профиль `base` (спред и свопы брокера)

Подробности: [results/trend_filter_ema.md](../../results/trend_filter_ema.md)
