# S10. Выход при развороте тренд-фильтра

**Семейство:** стратегия без ML (импульс) · **база:** B01 · **гипотеза:** H26 · **вердикт:** хуже базы

**Что проверяли.** К базе добавлен выход по развороту тренда: сделка закрывается по закрытию часа, когда гейт C становится противоположным её направлению (тренд — только по закрытой свече). Пересчитано на всех 8 рынках с дивидендами, стопом по гэпу и издержками базы.

**Зачем.** Держать позицию, пока тренд не развернулся, и не отдавать прибыль обратно; короче удержание — меньше свопов.

**Итог простыми словами.** Хуже базы, особенно на металлах. Срезаются крупные движения, ради которых стратегия держит позицию, а экономия на свопах этого не окупает.

**Издержки:** профиль `base` (спред и свопы брокера)
