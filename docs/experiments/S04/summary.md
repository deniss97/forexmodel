# S04. Проскальзывание 0.05% на входе и выходе

**Семейство:** стратегия без ML (импульс) · **база:** S03 · **гипотеза:** — · **вердикт:** учтено в базе

**Что проверяли.** Сделки S03, но исполнение хуже на 0.05% цены при входе и при любом выходе — по стопу, трейлингу и по времени. Считается по готовым сделкам: из результата каждой вычитается 0.1%.

**Зачем.** Вход в следующую минуту после сигнала частично уже несёт проскальзывание, но, чтобы не обманывать себя, 0.05% на сторону закладываем всегда (0.1% — перебор, договорённость 11.10).

**Итог простыми словами.** Небольшая потеря, значимость сохраняется. Это поправка, а не эксперимент — она входит в базу B01.

**Издержки:** профиль `base` (спред и свопы брокера)
