# Банк источников данных: что нужно сейчас и чего в нём нет (22.10)

Банк Тимура ([страница](https://claude.ai/artifact/Smm6fmtHmgD95rZonFp6Kd), версия 14.10) — 85 источников в 12 разделах,
собран под серебро: COMEX, Лондон, Шанхай. Первый этап запуска — акции Мосбиржи в лонг через Т-Инвестиции, металлы —
вторым этапом. Для Мосбиржи в банке одна запись (S010), а брокер в разделе «Брокерские и исполнение» — только IBKR.
Ниже — что из банка у нас уже есть, что проверено запросами 22.10 и какие записи предлагаю добавить в формате банка.
Сам банк не менял: он в другой организации, записи вносит Тимур.

## Что проверено 22.10 запросами к ISS

| что | итог |
|---|---|
| Свечи акций TQBR | бесплатно; минутки SBER есть как минимум с 19.12.2011 |
| Фьючерсы: список контрактов | все контракты серии вместе с истёкшими (`statistics/…/series?show_expired=1`), SILV — с 2007 года |
| Фьючерсы: свечи истёкших контрактов | бесплатно, минутки как минимум с 2015 (SVZ5_2015); у старых контрактов код с годом |
| FUTOI — позиции физлиц и юрлиц по фьючерсам | каждые 5 минут с 03.01.2020 по SV, GD, BR, Si; бесплатно с задержкой 14 дней («Free users can't receive data for the last 14 days») |
| Индекс IMOEX | часовые свечи бесплатно, как минимум с 2015 |
| AlgoPack, Super Candles (tradestats) | «Информация доступна только подписчикам» |
| cbr.ru | с сервера не ответил — не проверено |

Всё бесплатное из этой таблицы качает `scripts/moex_data.py` (и ноутбук `notebooks/moex_download.ipynb`):
акции, фьючерсы с истёкшими контрактами и склейкой, FUTOI.
