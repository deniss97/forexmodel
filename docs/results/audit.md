# Аудит расчёта импульсной стратегии: независимый симулятор, гэпы, дрейф

Дата: 2026-10-05. Все результаты стратегии до сих пор считались двумя движками, написанными
одной рукой с одинаковыми допущениями (`forexmodel/simulation` и быстрый
`scripts/early_entry.py`). Ошибка в них была бы незаметна. Здесь три проверки:

1. **независимый симулятор** с нуля — свой ресемплинг, свой ATR, явный поминутный цикл
   (`scripts/audit_simulator.py`), сверка с существующим расчётом;
2. **исполнение стопа при гэпе** — оба движка исполняют стоп по его уровню, даже если минута
   открылась уже за ним; измерено, сколько это стоит;
3. **разложение дохода на дрейф и остаток** (`scripts/drift_decomposition.py`) — не является ли
   стратегия переупакованным «купи и держи».

## Итог

| проверка | результат |
|---|---|
| данные | 8 инструментов: время монотонно, дублей нет, нарушений OHLC 0–2 бара на 2–4 млн, кэш совпадает с CSV (расхождения ≤ 1e-4 — округление float32) |
| независимый симулятор | число сделок совпадает с точностью до 1–2, итог по инструменту — не хуже ±7 п.п., портфель +144.6% против +144.1%. **Расчёт верный** |
| стоп при гэпе | на акциях MOEX исполнение по уровню завышает итог на **11–17 п.п. на инструмент** (LKOH +135 → +121, MOEX +54 → +37, GAZP +258 → +245, SBER +251 → +240, MTSS +21 → +9); форекс и крипта почти без изменений; портфель 8 — **+144.6% → +135.4%**. В симулятор добавлен режим `simulation.stop_fill: gap`; штатный walk-forward на 4 основных инструментах: портфель +196% → +187% (§4) |

## 1. Данные и независимый симулятор

Проверки данных ([audit/data_checks.csv](audit/data_checks.csv)): для каждого инструмента
монотонность времени, дубли, `high ≥ max(open, close) ≥ min(open, close) ≥ low`, доля минут без
движения (у MTSS 17% — неликвид), выборочная сверка 50 тыс. строк кэша с исходным CSV.

Независимый симулятор написан заново: часовые бары — `groupby(floor('h'))`, ATR(14) — среднее
true range, сигнал — ход за 6 ч ≥ 3 ATR, вход по open минуты через минуту после закрытия часа,
стоп и трейлинг 6 ATR с активацией +3 ATR явным циклом по минутам, выход не позже 240 ч, позиции
без перекрытия, комиссия 0.04%. Общего кода с существующими движками нет; единственная общая
часть — колонка гейта C из `impulse_universe.hourly`, чтобы проверить движок отдельно от гейта.

Сверка с существующим расчётом (исполнение по уровню стопа, 2015–2026,

## 2. Исполнение стопа при гэпе

Оба движка (`forexmodel/simulation/exits.py: trailing_exit`, `scripts/entry_rules_lab.py: _trailing`)
при касании стопа исполняют сделку по уровню стопа. Если минута открылась уже за стопом (ночной
гэп, дивидендная отсечка у акций), реальная цена — open этой минуты, хуже. Независимый
симулятор считает оба режима ([audit/audit_results.csv](audit/audit_results.csv)):

| инструмент, гейт C | по уровню стопа | по open при гэпе | разница |
|---|---|---|---|
| серебро | +242.5 | +241.0 | −1.5 |
| золото | +47.6 | +43.6 | −4.0 |
| ETH | +146.7 | +146.7 | 0 |
| LKOH | +135.3 | +121.0 | **−14.3** |
| GAZP | +258.2 | +244.6 | **−13.6** |
| SBER | +250.9 | +240.3 | **−10.6** |
| MOEX | +54.2 | +37.0 | **−17.2** |
| MTSS | +21.1 | +9.0 | **−12.1** |
| **портфель 8** | **+144.6** | **+135.4** | −9.2 |

По годам портфель теряет 0.1–1.8 п.п. в год, ровно; концентрации в одном годе нет.

**Сделано:** в штатный симулятор добавлен параметр `simulation.stop_fill: level | gap`
(по умолчанию `level`, чтобы прежние результаты воспроизводились; для честной оценки акций —
`gap`). Тест — `tests/test_simulation.py::test_stop_fill_gap_uses_open_when_bar_opens_beyond_stop`.
Проверка штатным симулятором на 4 основных инструментах — ниже (§4).

Это касается и модели CatBoost на акциях (LKOH, выход 10 ч / стоп 2 ATR): там гэпы через стоп
тоже исполнялись по уровню. Вместе с некорректированными дивидендами
([impulse_instruments.md](impulse_instruments.md) §1) это два источника оптимизма по акциям.

## 3. Дрейф или сигнал

Разложение по каждой сделке: дрейф = сторона × средний часовой лог-рост инструмента за этот год ×
торговых часов в сделке; остаток = результат − дрейф. Дрейф года берётся по факту: это
диагностика, а не правило. Гейт C, 2015–2026, % после комиссии
([audit/drift_decomposition.csv](audit/drift_decomposition.csv)):

| инструмент | рост инструмента | итог стратегии | из них дрейф | остаток | t остатка |
|---|---|---|---|---|---|
| серебро | +375% | +242.5 | +24.5 | **+218.0** | 2.69 |
| золото | +283% | +47.6 | +10.3 | +37.3 | 0.87 |
| ETH | +1457% | +146.7 | +20.9 | +125.8 | 0.81 |
| LKOH | +75% | +135.3 | +24.8 | +110.5 | 1.74 |
| GAZP | −13% | +258.2 | +5.9 | **+252.4** | 2.44 |
| SBER | +496% | +250.9 | +28.2 | **+222.8** | 2.80 |
| MOEX | +139% | +54.2 | +31.3 | +22.9 | 0.34 |
| MTSS | −2% | +21.1 | +3.6 | +17.4 | 0.25 |
| **портфель 8** | | **+144.6** | **+18.7** | **+125.9** | |

По сторонам:

| | лонг: итог / дрейф / остаток | шорт: итог / дрейф / остаток |
|---|---|---|
| серебро | +188 / +63 / +124 | +55 / −39 / **+94** |
| золото | +88 / +52 / +36 | −41 / −42 / +1 |
| ETH | +194 / +93 / +101 | −47 / −72 / +25 |
| SBER | +172 / +72 / +101 | +79 / −43 / **+122** |
| GAZP | +148 / −3 / +151 | +110 / +9 / +101 |

* **Дрейф объясняет лишь 13% дохода портфеля.** Остаток положительный на всех 8 инструментах,
  значим (t > 2) на серебре, GAZP и SBER.
* **Шорты на металлах убыточны только из-за роста инструмента.** Их остаток положительный:
  сигнал работает в обе стороны, а против стратегии играл дрейф. На GAZP, который за период
  упал, лонги и шорты дали почти одинаково (+148 и +110).
* **Стратегия не повторяет инструмент:** корреляция месячных результатов с месячными
  доходностями инструмента от −0.12 до +0.27, бета −0.11…+0.22. В позиции она около трети
  времени в каждую сторону ([audit/drift_monthly.csv](audit/drift_monthly.csv)).

Для торговли отсюда следует: убирать шорты на металлах не стоит. Их минус — ставка на то, что
металлы продолжат расти так же, как в 2015–2026.

## 4. Штатный симулятор с исполнением по гэпу

Walk-forward 2016–2026, импульс 6 ч / 3 ATR, выход 240 ч / 6 ATR, итог % после комиссии
(`walk_forward/*_exit_240h6_gap__*.csv`):

| инструмент | по уровню стопа | по open при гэпе | разница | с гэпом и проскальзыванием 0.1% |
|---|---|---|---|---|
| серебро | +252.1 (t 3.15) | +250.6 (t 3.13) | −1.5 | +218.4 |
| LKOH | +157.5 (t 2.44) | +145.2 (t 2.24) | **−12.3** | +97.0 |
| GAZP | +230.5 (t 1.97) | +216.7 (t 1.87) | **−13.8** | +140.8 |
| SBER | +144.8 (t 2.05) | +134.4 (t 1.89) | **−10.4** | +96.3 |
| **портфель 4 (по 1/4)** | **+196** | **+187** | −9 | +138 |

Штатный симулятор даёт ту же картину, что независимый (§2). Для акций честная оценка —
с `stop_fill: gap`; вместе с дивидендами (цены акций не скорректированы на отсечки) итог по
акциям MOEX следует считать завышенным ещё на 25–40% относительно этих цифр
([impulse_instruments.md](impulse_instruments.md) §1).

## 5. Контекст импульса: подтверждение, час, день недели, сила

`scripts/impulse_context.py`, 17 тыс. сигналов базовой стратегии (все кандидаты, с перекрытиями,
результат до вычета — больше наблюдений), средний результат сделки после комиссии
([audit/impulse_context.txt](audit/impulse_context.txt)):

| разрез | 2015–20 | 2021–26 | вывод |
|---|---|---|---|
| связанный инструмент идёт туда же (серебро ↔ золото, акции друг с другом) / не идёт | +0.15 / +0.67 | +0.50 / +0.31 | знак меняется — правила нет |
| сила хода 3–3.5 / 3.5–4 / 4–5 / > 5 ATR | +0.19 / +0.24 / +0.35 / +0.40 | +0.38 / +0.44 / +0.51 / +0.34 | сильнее — чуть лучше, но > 5 ATR в 2021–26 хуже; порог 3 ATR оставить |
| день недели | лучший четверг, худшая пятница | лучшие пятница и вторник, худший понедельник | шум |
| час сигнала, акции MOEX | утро 9–11 МСК +0.1…+0.3, вечер 19–21 +1…+1.9 (n = 15–26) | утро −0.1…+0.4, 15–23 МСК +0.5…+1.2 | вечерняя сессия выглядит лучше, но до 2020 её почти не было — проверить нечем |
| час сигнала, форекс | ночь/утро по времени источника лучше дня | день лучше ночи | шум |

Ни один контекст не меняет результат с одним знаком в обоих периодах. Фильтровать импульсы по
контексту не стоит; единственный кандидат на будущее — вечерняя сессия MOEX, когда наберётся
история.
