# Ночной перебор параметров импульса (H50)

`scripts/night_search.py` сам перебирает комбинации параметров из списка ТЗ 15.10 на импульсной стратегии
и выбирает лучшие **только по выбору 2016–2020**. Проверка 2021–2026 нужна только для отчёта, в выборе она
не участвует. Издержки — как у базы B01 (или профиль биржи для акций).

> Хранение (20.10): первая версия перебора (подбор фильтров к импульсу) закрыта, её база проб и кандидаты сделок (`reports/night_search/trials.sqlite`, `cand/`, 1.4 ГБ) удалены. Оставлены подготовленные свечи `reports/night_search/feat` — на них считают `strategy_search.py`, `second_search.py`, `known_strategies.py`.

## Как запустить

```
setsid nohup scripts/queues/night_search.sh > /dev/null 2>&1 &     # всё: подготовка, два поиска, отчёты
HOURS_METALS=12 HOURS_P4=6 setsid nohup scripts/queues/night_search.sh > /dev/null 2>&1 &   # дольше
```

Или по шагам:

```
python scripts/night_search.py prepare --workers 4                 # ~2–2.5 ч один раз
python scripts/night_search.py search --hours 8 --scope металлы --costs base
python scripts/night_search.py search --hours 8 --scope "портфель 4" --costs exchange
python scripts/night_search.py report --scope металлы --costs base  # reports/night_search/report_*.md
python scripts/night_search.py finalize --scope металлы --top 3     # финалисты → журнал (S36…)
python scripts/experiments.py                                      # пересчитать журнал
```

Всё продолжается после обрыва или перезагрузки: готовые сделки лежат в `reports/night_search/cand/`, пробы —
в `reports/night_search/trials.sqlite`. Повторный запуск поиска добавляет новые пробы к старым.

## Что перебирается

| параметр | значения |
|---|---|
| период ATR (порог импульса и стоп) | 10, 14, 20 |
| импульс: окно × порог | 4 / 6 / 8 ч × 2.5 / 3 / 3.5 ATR |
| выход (21) | стоп 1.5 / 2 / 2.5 / 3 ATR × тейк 2 / 3 / 4 ATR или трейлинг того же размера; стоп и трейлинг 6 ATR (база); Chandelier 3·ATR(22); по времени 10 / 20 / 50 ч |
| фильтр направления (130) | без фильтра; гейт C; «всегда лонг»; EMA 9–200, наклон EMA, пары 9/21, 12/26, 20/50, 50/200 и Фибоначчи; MACD 12/26/9, 8/17/9, 5/35/5, 19/39/9 × три вида сигнала; Supertrend (10, 3), (7, 3), (10, 2); Дончиан 20/10 и 55/20; Кельтнер; Боллинджер; ADX; KAMA — на 1 ч, 4 ч и днях; 14 вариантов трёхслойного фильтра |
| ADX(14) | нет / > 20 / > 25, на 1 ч или 4 ч |
| волатильность | нет / ATR14 / ATR100 > 1 / перцентиль ATR за 250 баров > 0.5 или 0.7 |
| RSI | нет / RSI14 не перекуплен / RSI14 по ходу / RSI2 не перекуплен |
| сжатие (вчерашний день) | нет / NR7 / NR4 / inside bar / NR7 + inside bar |
| уровни | нет / пробой вчерашнего дня, 20 дней (и + 0.25 ATR), 55 дней / верх 20-дневного диапазона / свежий 20-дневный экстремум / пробой фрактала K = 3 / пробой азиатской сессии в Лондон (металлы) / запас до уровня ≥ 0.5 или 1 ATR |
| стороны | обе / только лонг / акции только лонг |
| размер | 1 / по риску: объём = риск / (стоп · ATR), нормирован на медиану |

Около 3·10⁹ комбинаций — поэтому поиск: сначала случайные комбинации, потом всё чаще мутации лучших.

**Ловушки из ТЗ учтены.** Максимумы и минимумы берутся по прошлым дням, без текущего. Фрактал виден только
через K = 3 бара после вершины. Торговый день металлов начинается в 17:00 по времени данных: данные
металлов — в чикагском времени, пятница закрывается в 16:59, воскресенье открывается в 17:00, как сессия
COMEX / Globex. Азиатская сессия — 18:00–01:59, Лондон — с 02:00. В прошлых проверках S30–S32 день металлов
резался по полуночи. NR7 считается по дневкам, не по часам.

**Не вошло.** Вход на ретесте и отложенные buy-stop / sell-stop ордера (сигнал — всегда закрытие часа),
круглые числа и число касаний уровня.

## Как устроен расчёт

Для каждой пары «период ATR × выход» (63 пары) все сигналы импульса (объединение окон и порогов) один раз
прогоняются **штатным симулятором**: дивиденды, стоп по гэпу, издержки B01 и профиль биржи. Проба только
отбирает сигналы маской и цепочкой без перекрытия, как это делает симулятор, — около 20 мс на пробу.
Комбинация базы воспроизводит B01: металлы на проверке +41.65% против +41.30%, разница — одна сделка на
стыке 2016/2017.

## Защита от подгонки

1. **Цель — PF на выборе** при числе сделок не меньше 30% от базы.
2. **Устойчивая оценка.** Для претендентов в сотню лучших дополнительно считаются 8 соседей (один
   параметр другой); оценка — медиана PF пробы и соседей. Одиночный выброс среди плохих соседей получает
   низкую оценку. Финалисты отбираются по ней.
3. **Walk-forward самого поиска — главная строка отчёта.** На год Y берётся лучшая комбинация по годам
   до Y и торгует год Y. Если сумма за 2021–2026 не лучше базы, найденные «лучшие» — подгонка.
4. **Связь выбор → проверка** по всем пробам. Около нуля — выбор по прошлому не переносится.

## Пробный прогон (16.10, 2.5 мин, только выход базы)

Даже за 2.5 минуты поиск нашёл комбинации с PF 1.9 на выборе металлов (база — 0.94). На проверке у них
PF около 1.0 и итог около 0% против +41.6% у базы. Walk-forward поиска: **−6.9% против +41.6%**. Лучшие
комбинации — жёсткие фильтры (ADX 1 ч > 25, свежий 20-дневный экстремум, окно 8 ч / 3.5 ATR), которые
оставляют треть сделок, а на них PF на выборе раздувается случайно. Ночной прогон покажет, держится ли
эта картина на всём пространстве. Отчёт пробного прогона — [night_search/report_металлы_base.md](night_search/report_металлы_base.md). Эта версия подбирала фильтры к импульсу — не та постановка; заменена перебором самостоятельных стратегий, см. [strategy_search.md](strategy_search.md).
