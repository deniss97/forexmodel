# Размер позиции по волатильности, диффузионная модель TokDiT и синтетические данные

Дата: 2026-09-28. Контекст: по всем прежним экспериментам
([model_changelog.md](model_changelog.md)) у моделей серебра и LKOH нет преимущества после
комиссии. На сделку до комиссии +0.03…+0.06%, это того же порядка, что комиссия 0.04%. Здесь
проверены три направления, которые меняют постановку задачи, а не модель:

1. **Прогноз волатильности → размер позиции.** Преимущество в процентах растёт с волатильностью
   на входе, а комиссия от неё не зависит. Значит, в тихие периоды торговать меньше или не
   торговать совсем, в волатильные — больше.
2. **Диффузионная модель TokDiT для направления.** Проект `../TokDiT`, ветка
   `d.a.lanovenko-ablation_study`.
3. **Синтетические данные из генераторов TokDiT** для обучения CatBoost, MLP и TokDiT.

Порядок выбран по соотношению «ожидаемая польза / стоимость». Сигнал волатильности уже был
виден в данных (серебро по терцилям волатильности: −0.030 / +0.010 / +0.058% на сделку), а
проверка стоит 1–2 часа. TokDiT учится с нуля на CPU (обученных весов нет, GPU нет) и считается
часами. Синтетика информации о рынке не добавляет, поэтому ожиданий от неё меньше всего.

**Итог.**

| направление | результат | вердикт |
|---|---|---|
| Размер по волатильности | Сделка лучше на всех 3 seed, на **обоих** инструментах. Серебро: t после комиссии 1.77 → 2.16–2.18. LKOH: −1.46 → +0.20 | ✅ слабо: первое изменение, устойчивое по seed и инструментам; без 2026 года на серебре не значимо |
| TokDiT, направление | 2021–2022: AUC **0.501 / 0.500**, то есть случайное угадывание. CatBoost и MLP на тех же окнах 0.48–0.52 | ⏳ идёт (2023–2026); пока ❌ |
| Синтетика для CatBoost / MLP | AUC на реальном будущем 0.491–0.515 против 0.510 на реальных; после комиссии минус у всех | ❌ |
| Синтетика для TokDiT | в очереди после TokDiT на реальных | ⏳ |

## 1. Прогноз волатильности и размер позиции

### Что сделано

* `forexmodel/models/volatility.py`, секция конфига `volatility` (по умолчанию выключена).
  * **Цель:** средний true range следующих `horizon` баров в % цены,
    `mean(TR[i+1..i+h]) / close[i] · 100`. `horizon` по умолчанию равен `labeling.horizon`.
  * **Модель:** CatBoostRegressor на log цели по признакам primary, с хронологическим holdout и
    ранней остановкой, затем дообучение на всём train.
  * **Наивная альтернатива** (`source: atr`): текущий ATR в % цены.
  * **Размер позиции:** `ratio = прогноз / опорный уровень`; `size = 0` при `ratio < min_ratio`,
    иначе `min(ratio^power, cap)`. Опорный уровень — медиана по последним `ref_bars` барам
    обучающей выборки. При `power = 0` это чистый фильтр: 1 выше порога, 0 ниже.
* **Защита от утечек.** Цель считается на непрерывном ряде, **обрезанном по началу test**, поэтому
  у последних `horizon` баров train она пустая и в test не смотрит ни при каком embargo. Тест:
  `tests/test_volatility.py`, где проверено, что цель бара зависит только от его горизонта.
* **Симулятор.** Позиция размера 0 не открывается и время не занимает. Результат и комиссия
  умножаются на размер. В сделках появились колонки `size` и `gross_unit_pct` (результат на
  единицу).
* **Walk-forward.** Варианты `vol:<min_ratio>:<power>` (прогноз моделью) и
  `volatr:<min_ratio>:<power>` (наивный ATR) прогоняются на одной обученной модели окна вместе с
  базовым `cb`. Различие между вариантами — только размер позиции.

```
python scripts/walk_forward.py -c configs/silver.yaml --years 2019 2026 \
  --set catboost.random_seed=42 --set nn.enabled=false --set meta.enabled=false \
  --set simulation.signal_source=cb --set volatility.enabled=true --name silver_vol_s42 \
  --variants cb volatr:0:1 volatr:1:0 vol:0:1 vol:1:0 vol:0.8:1
```

### Качество прогноза

Корреляция log прогноза с log факта на holdout: **модель 0.76, наивный ATR 0.40** (серебро, все
годы). Выигрыш модели в основном идёт от часа суток: внутридневной профиль волатильности
предсказуем.

### Серебро: walk-forward 2019–2026, 3 seed

Критерий — t-статистика результата сделки после комиссии. Она не зависит от масштаба, поэтому
варианты с разным средним размером сравнимы. Суммы в % растут почти вдвое из-за размера > 1 в
2026 году, мерой улучшения они не служат.

| вариант | размер ср. | t после комиссии (42 / 7 / 1) | среднее | без 2026 | нетто на ед. размера, без 2026 |
|---|---|---|---|---|---|
| `cb` (без размера) | 1.00 | 1.48 / 1.82 / 2.02 | **1.77** | 0.47 | +0.011% |
| `volatr:0:1` (∝ ATR) | 1.18 | 1.82 / 2.40 / 2.26 | **2.16** | 0.84 | +0.025% |
| `volatr:1:0` (только ATR ≥ медианы) | 1.00 | 1.68 / 2.39 / 2.46 | **2.18** | 0.93 | +0.032% |
| `vol:0:1` (∝ прогноз модели) | 1.35 | 1.75 / 2.13 / 2.09 | 1.99 | 0.66 | +0.018% |
| `vol:1:0` (прогноз ≥ медианы) | 1.00 | 1.42 / 1.98 / 2.01 | 1.80 | 0.47 | +0.012% |
| `vol:0.8:1` | 1.40 | 1.76 / 2.26 / 2.12 | 2.05 | 0.74 | +0.021% |

* Шарп на сделку у `volatr:0:1` выше, чем у `cb`, на всех 3 seed. Сделки те же, различаются
  только веса. Парный бутстрэп по сделкам: доля ≤ 0 равна 0.07 / 0.01 / 0.17.
* **Наивный ATR лучше модели**, хотя модель точнее прогнозирует волатильность. Модель ловит
  внутридневной профиль, а преимущество связано с уровнем волатильности режима, то есть с
  медленной частью.
* **Главная оговорка:** без 2026 года t остаётся < 1. Эффект направленный и устойчивый по seed,
  но основную пользу даёт волатильный 2026-й.

### LKOH: квартальный walk-forward 2024Q3–2026Q1, 3 seed

`configs/lkoh_2024_base_reg.yaml`, без тренд- и EV-фильтров.

| вариант | t после комиссии (42 / 7 / 1) | среднее | нетто на ед. размера |
|---|---|---|---|
| `cb` | −1.46 / −0.89 / −2.03 | **−1.46** | −0.022% |
| `volatr:1:0` | −0.13 / +0.50 / +0.21 | **+0.20** | +0.006% |
| `volatr:0:1` | | −0.78 | −0.016% |
| `vol:0.8:1` | | −0.20 | −0.004% |

Преимущества на LKOH нет, но **направление эффекта то же**: отказ от сделок в тихие периоды
улучшает сделку на всех 3 seed.

### Что с этим делать

* Практичный вариант — фильтр «не торговать при ATR ниже медианы хвоста train» (`volatr:1:0`).
  В конфиг по умолчанию он не включён: нужен вариант `source: atr` в пайплайне без
  walk-forward-обвязки, а значимость без 2026 года пока не доказана.
* Проверить на других инструментах, в первую очередь на золоте (`reports/_cache/gold_1h.pkl`).
* Опорный уровень считать по скользящему окну прошлого, а не по хвосту train: сейчас он
  фиксирован на весь год теста.

Результаты: [walk_forward/](walk_forward/), файлы `silver_vol_s*__*.csv` и `lkoh_vol_s*__*.csv`.

## 2. TokDiT для направления

### Постановка

`scripts/tokdit_direction.py`. Одна постановка для всех моделей:

* **Окно:** 96 часовых баров контекста + 10 баров горизонта (`labeling.horizon` серебра).
* **Путь окна:** `100·log(close)` минус значение в последнем баре контекста. Путь равен 0 в
  момент прогноза, в конце горизонта — доходности в %. Цель — знак в конце горизонта.
* **TokDiT:**
  * пресет `nano` (118 тыс. параметров), нормализатор `[ZNorm, Asinh]`;
  * учится с нуля на CPU: 1500 шагов Adam, батч 256, косинусный lr;
  * последние 10 точек скрыты маской, модель сэмплирует 32 продолжения (10 шагов сэмплера);
  * P(up) — доля сэмплов выше нуля в конце горизонта.
* **CatBoost и MLP** на тех же окнах: 95 доходностей контекста, делённые на их std в окне, и log
  этой std.
* **Метрики:** AUC и IC прогноза против факта; торговля по доле самых уверенных прогнозов (100%,
  30%, 10%), удержание 10 баров без перекрытия, комиссия 0.04%. Это проверка наличия информации,
  а не боевая симуляция: нет трейлинга и тренд-гейта.

### Как исключены утечки

* **Нормировка — только по контексту окна.** У TokDiT статистики ZNorm считаются по наблюдённым
  позициям (так устроен `TokDiT._apply_normalizer`), скрытый хвост в них не входит. Кроме того,
  при прогнозе значения хвоста обнуляются до передачи в модель. У CatBoost и MLP std берётся по
  доходностям контекста.
* **Код TokDiT, который не использован.** `RealSeriesSampler(normalize=True)` из
  `experiments/ablation_v21` z-нормирует **всё окно вместе с целью**. Для прогноза это утечка,
  поэтому он не используется.
* **Обучающие окна** целиком, включая горизонт, заканчиваются до 1 января года теста. Контекст
  тестового окна может уходить в прошлое, это законно.
* **Ранняя остановка CatBoost и MLP** идёт по последним 15% реальных окон train с зазором L+H
  окон от обучающих: перекрывающиеся окна не попадают в обе части. Синтетика в валидацию не
  попадает.
* **Статистики стандартизации MLP** считаются только по обучающей части.
* Тесты: `tests/test_tokdit_direction.py` (признаки не зависят от горизонта, окна и сделки
  корректны).

### Результаты (прогон идёт: готовы 2021 и 2022)

Прогноз по каждому 4-му бару теста, около 1.5 тыс. прогнозов в год:

| год | TokDiT AUC | CatBoost AUC | MLP AUC | t после комиссии, все сигналы (TokDiT / CB / MLP) | t, 10% самых уверенных (TokDiT) |
|---|---|---|---|---|---|
| 2021 | 0.501 | 0.525 | 0.514 | −1.5 / −0.4 / −1.8 | −0.7 |
| 2022 | 0.500 | 0.480 | 0.479 | +0.6 / −2.8 / −2.1 | −1.7 |

Обучение сходится (loss 1.12 → ~0.3), но **направление TokDiT не видит**: AUC ровно 0.5.
Ожидаемо: генеративная модель хорошо воспроизводит форму и разброс ряда, но извлечь направление
из окна цены, где его нет, не может. Следующая осмысленная проверка — **TokDiT как прогноз
разброса** (квантили 32 траекторий) для размера позиции, потому что размер по волатильности —
единственное, что пока сработало.

Результаты: [tokdit/tokdit_real.csv](tokdit/tokdit_real.csv), обновляется по мере прогона.

## 3. Синтетические данные

### Генераторы

* **FinStress** (`sampler/finstress`): финансовые ряды доходностей по статье FinStressTS.
  * `garch:3` — кластеры волатильности, автокорреляция ≈ 0;
  * `regime:3` — переключение режимов, acf1 ≈ +0.19, то есть моментум.
* **SamplerV21** (`sampler/synthetic`): общие ряды-уровни с трендами, сезонностью, событиями.
  Пресеты `realistic` и `wide`.
* Генераторы берутся с фиксированными пресетами и реальных данных не видят, поэтому test в них не
  протекает. Подгонка генератора под реальные ряды (`tune_generator.py`) не делалась: она
  приблизила бы форму рядов, но не добавила бы информации о направлении.
* Синтетике присваивается масштаб случайного реального окна train (std шага контекста), чтобы
  признак log std и значения были в том же диапазоне.

### CatBoost и MLP: серебро 2019–2026, 3 seed, около 43 тыс. прогнозов на прогон

| обучение | CatBoost AUC (мин. по seed) | MLP AUC | CB t после комиссии: все / 10% самых уверенных |
|---|---|---|---|
| только реальные | **0.510** (0.506) | 0.501 | −1.6 / +0.4 |
| реальные + GARCH | 0.512 (0.510) | 0.507 | −1.4 / +0.2 |
| реальные + regime | 0.506 (0.498) | 0.497 | −1.0 / +1.2 |
| реальные + V21 realistic | 0.514 (0.513) | 0.503 | −2.4 / −1.0 |
| реальные + V21 wide | 0.512 (0.510) | 0.505 | −2.4 / −0.5 |
| только GARCH | 0.508 (0.507) | 0.507 | −0.8 / −0.1 |
| только regime | **0.491** (0.488) | 0.498 | −1.6 / −0.9 |
| только V21 realistic | **0.515** (0.512) | 0.502 | −2.6 / −0.9 |
| только V21 wide | 0.500 (0.497) | 0.500 | −2.2 / −2.0 |

Выводы:

* **Синтетика не помогает.** Различия ±0.005 AUC при ошибке около 0.003, после комиссии минус у
  всех. +1.2 у «реальные + regime» — одно сравнение из 18, это не значимо.
* **Модель, не видевшая серебра (только V21 realistic), не хуже обученной на серебре.** Значит, в
  окне цены модели находят только общее свойство рядов (краткосрочный откат), а не особенность
  инструмента. Поэтому больше таких же рядов не прибавляет информации.
* **Генератор с моментумом (regime) учит обратному**, и AUC падает ниже 0.5: серебро на 10 часах
  скорее откатывается.
* MLP стабильно слабее CatBoost.

Подробно: [tokdit/cbmlp_summary.txt](tokdit/cbmlp_summary.txt), по годам — `tokdit/cbmlp_*.csv`.

### TokDiT с синтетикой

В очереди после TokDiT на реальных: смесь 1:1 с V21 `realistic` и с FinStress `regime:3`, те же
годы и настройки. Если TokDiT на реальных данных останется на AUC ≈ 0.5, эти прогоны можно не
ждать: CatBoost на тех же данных показал, что синтетика информации о направлении не добавляет.

## Воспроизведение

* Окружение: `.venv` проекта плюс `pydantic` (нужен TokDiT). TokDiT импортируется из
  `../TokDiT` (путь меняется переменной `TOKDIT_PATH`), в самом проекте TokDiT ничего не
  менялось.
* Волатильность: команда выше, seed 42 / 7 / 1; для LKOH добавить
  `--quarters 2024Q3 2026Q1 --set simulation.use_trend_filter=false --set simulation.use_expected_value_filter=false`.
* CatBoost/MLP и синтетика:
  `python scripts/tokdit_direction.py --years 2019 2026 --models catboost mlp --seed 42 [--synthetic finstress:garch:3 [--synthetic-only]] --name ...`
* TokDiT:
  `python scripts/tokdit_direction.py --years 2021 2026 --test-stride 4 --steps 1500 --samples 32 --sampler-steps 10 --pred-batch 512 --models tokdit catboost mlp --name tokdit_real`
  Около 40 минут на год на 8 ядрах CPU.
