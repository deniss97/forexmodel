# Профиль объёма по уровням с затуханием, по коду Тимура (H40)

Код Тимура — S_HorizonVolume.ipynb (прикреплён к H40 в банке): профиль объёма по уровням цены, где старые сделки весят меньше (halflife — «время жизни позиции»), POC, зона стоимости 70%, узлы HVN и провалы LVN и расстояния до ближайших как признаки для модели. Данные — лента LKOH (TQBR) и фьючерсов серебра (основной контракт дня), 2024–2026, уровни — сетка 0.1% цены. Расчёт — `scripts/h40_profile.py`.

**Критерий (банк, до расчёта):** признак профиля с затуханием (24 или 120 ч) даёт |IC| ≥ 0.03 одного знака в обеих половинах данных на обоих инструментах и больше по модулю, чем у профиля без затухания (70 ч, как в L02); только тогда — модель LKOH.
