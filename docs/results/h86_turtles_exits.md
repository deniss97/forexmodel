# Пробой 55 дней с выходами настоящих «Черепах» (H86)

Гипотеза из скептика к H47: там пробой проверялся с короткими выходами S42, а не по системе «Черепах». Здесь — дневные свечи 21 акции, вход по пробою 55-дневного максимума при гейте C вверх, стоп 2 × ATR(20 дней), выход по минимуму 20 дней, без срока, одна позиция на бумагу, издержки 0.2% за круг. Расчёт — `scripts/h86_turtles_exits.py`.

**Критерий (банк, до расчёта):** на 18 акциях без GAZP, SBER, LKOH PF лучше 95% случайных входов в тренде с теми же выходами в обоих периодах и выше 1.1. Случайных наборов — 500.
