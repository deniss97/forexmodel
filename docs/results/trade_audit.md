# Сверка сделок журнала с правилом и графиком

Предложение созвона 23.10 (T42): то, что видно на графике журнала, машинно сверяется с правилом стратегии. По каждому эксперименту импульса, перебора и тренд-фильтра: цена входа и выхода — внутри часовой свечи страницы того часа; сделка не дольше предела правила; вход — по тренд-фильтру на часе сигнала, где правило этого требует (импульс — гейт C, эксперименты с зонами трёхслойного фильтра — трёхслойный). Расчёт — `scripts/trade_audit.py`, по бумагам — [trade_audit.csv](trade_audit.csv).

## Вывод (24.10)

**В 48 из 50 экспериментов сделки на графике согласованы с правилом: входы и выходы внутри свечей своего часа, сделки
не дольше предела, у импульса все входы по гейту C, у H59, H60 и их переноса — по трёхслойному фильтру. Найдена и
исправлена одна ошибка графика, ещё три расхождения — известные допущения симулятора и движка перебора.**

1. **Исправлено: цена выхода на графике съезжала на дивиденд.** `experiments.raw_prices` переводит цены сделок в
   масштаб сырых свечей по множителю дивидендов первой минуты *не раньше* момента сделки. Выход «по сроку» пишется концом
   часа (например, 19:00 в пятницу), такой минуты нет, и бралась первая минута следующей сессии — уже после отсечки. Пример:
   S53, CHMF 14.06.2019 — выход на графике на 3.2% ниже свечи, ровно на дивиденд 17.06. Теперь берётся последняя минута не
   позже момента сделки. На метрики это не влияет, только на график; карточки S52–S55 пересобраны.
2. **S01 — стоп по уровню при гэпе** (2–4% выходов по акциям ниже свечи открытия): так и было в первой версии; S02 исправил
   исполнение по цене открытия, у него 100%.
3. **S35 — тейк по уровню при гэпе вверх** (2–4% выходов по акциям): рынок открылся выше тейка, а симулятор берёт уровень
   тейка, а не лучшую цену открытия. Допущение консервативное — результат S35 немного занижен.
4. **Сделки нулевой длины в движке перебора** — S46 15 сделок, S53 44 (из 413 и 957): сигнал выхода уже стоит на часе
   входа, сделка закрывается по цене входа и платит только издержки. Результат S46/S48 этим немного занижен; в живой торговле
   такие входы надо пропускать (бумажный режим S46/S48 их тоже показывает).
5. **Мелкое:** единицы сделок с входом или выходом в 09:01 (час утреннего аукциона) не попадают в свечу — свечи страницы и
   движок по-разному относят минуту 09:59 к часу; у S01, S02 1% входов не по гейту C страницы (ранние прогоны, гейт считался
   по окнам года).
