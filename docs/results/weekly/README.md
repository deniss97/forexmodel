# Еженедельные отчёты

Раз в неделю — презентация: только то, что сделано за неделю, как это меняет общий результат
исследования, есть ли улучшения, и планы. Подробности каждого эксперимента — в
[журнале изменений](../model_changelog.md).

    python scripts/weekly_charts.py --week <дата понедельника>     # 2026-10-05, 2026-10-12
