# Нейросеть вместо CatBoost (H64)

Тимур: в его опыте нейросеть (torch) по результатам и «адаптивности» превосходила CatBoost. В конвейере уже есть нейросеть CNN-BiLSTM (`forexmodel/models/nn_cnn_bilstm.py`: окно 20 часов, свёртка + двунаправленный LSTM, 40 эпох с ранней остановкой, те же 81 признак и та же разметка на 3 класса). Сравнение A/B на LKOH при настройках H63: без меты, тренд-гейт C, разметка atr_asym, годовой walk-forward 2018–2026, seed 42, 7, 1, издержки биржи. Сигнал — только сеть против только CatBoost (база L10). Расчёт — `scripts/queues/h64_nn.sh`, `scripts/h64_nn.py`.

**Критерий (банк, до расчёта):** PF сети выше CatBoost и на 2018–2020, и на 2021–2026 (среднее по 3 seed); «полезна для торговли» — если вдобавок PF на проверке > 1.
