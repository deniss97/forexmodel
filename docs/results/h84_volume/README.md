# Объём по уровням LKOH (H84)

Страница для ручного разбора графика: часовые свечи недели и объём сделок на каждом уровне цены — сколько акций куплено
(сделку начал покупатель) и продано (сделку начал продавец). Отметки по коду Тимура `S_HorizonVolume`: POC, зона стоимости
70%, узлы высокого объёма (HVN) и провалы между ними (LVN). Шаг уровня — 1, 5 или 10 ₽, неделя выбирается списком или
стрелками ← →.

## Как открыть без входа на claude.ai

1. Откройте [lkoh_volume_levels.html](lkoh_volume_levels.html) на GitHub и нажмите **Download raw file** (значок со стрелкой
   справа над файлом). Или сохраните прямую ссылку:
   <https://raw.githubusercontent.com/deniss97/forexmodel/main/docs/results/h84_volume/lkoh_volume_levels.html>
   (в браузере: правая кнопка → «Сохранить как…», имя файла с окончанием `.html`).
2. Откройте сохранённый файл двойным щелчком — в Chrome, Edge, Firefox или Яндекс Браузере.

Файл самодостаточный: данные и библиотека графиков (Plotly) внутри, интернет не нужен (без интернета шрифты будут
системные). Размер — около 5 МБ.

## Откуда данные и как обновляется

* История — секундные агрегаты обезличенных сделок Мосбиржи (TQBR) с января 2024 по 06.04.2026.
* Свежие дни — сделки, которые сервер каждую ночь забирает с Мосбиржи (`scripts/moex_trades.py`, cron 00:20 и 06:20 по
  Москве). Между апрелем 2026 и началом сбора недель нет: прошлые сделки биржа отдаёт только по подписке.
* Файл пересобирается каждый понедельник в 06:50 по Москве (`scripts/queues/h84_weekly.sh`) и попадает сюда сам — для
  свежей версии скачайте файл заново.
* Покупка и продажа — по стороне инициатора сделки (поле BUYSELL у биржи); лот LKOH — 1 акция.

Собрать вручную: `python scripts/h84_volume_weeks.py` (история из ленты — один раз, `--history`).
