# Разметка фигур теханализа — страница для оценки (H74)

Страница для Тимура и Тагира: 208 примеров фигур, которые нашёл алгоритм разметки, на дневных свечах 19 акций
Мосбиржи (2015–2026). По каждому примеру нужно сказать «это фигура» или «не фигура» — критерий гипотезы H74 требует
не меньше 80% подтверждений. Оценки сохраняются в браузере и выгружаются одним файлом CSV.

## Как открыть без входа на claude.ai

1. Откройте [patterns.html](patterns.html) на GitHub и нажмите **Download raw file** (значок со стрелкой справа над
   файлом). Или сохраните прямую ссылку:
   <https://raw.githubusercontent.com/deniss97/forexmodel/main/docs/results/h74_patterns/patterns.html>
   (в браузере: правая кнопка → «Сохранить как…», имя файла с окончанием `.html`).
2. Откройте сохранённый файл двойным щелчком — в Chrome, Edge, Firefox или Яндекс Браузере.

Файл самодостаточный: данные внутри, библиотек и интернета не нужно, размер около 0.9 МБ.

## Что на странице

* Сверху — выбор фигуры, половины истории (выбор до 2021 года / проверка с 2021) и «только неоценённые».
* Каждая карточка: бумага, дата пробоя, измеренные числа фигуры (например, «дно ±2.4%, глубина 14%») и пороги,
  при которых она найдена; ниже — свечи: кружки — опорные точки фигуры, пунктир — уровень или линия, по которой
  считается пробой, синяя вертикаль — день пробоя (первое закрытие выше уровня).
* Кнопки «это фигура / не фигура / не знаю». Справа сверху видно, сколько оценено и какая доля «фигура».
* «Скачать оценки» — файл `h74-ocenki.csv`, его можно прислать в группу; по нему считается вторая часть критерия.

Оценки лежат в памяти браузера (localStorage): можно закрыть вкладку и вернуться, но при открытии файла в другом
браузере или в режиме инкогнито они не подхватятся.

## Откуда берутся примеры

Разметка — `scripts/h74_patterns.py`, страница — `scripts/h74_page.py` (примеры выбираются случайно, но при каждом
